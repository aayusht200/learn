# JavaScript Objects – Practice Guide

This guide will help you practice key JavaScript object concepts. Work through the exercises below without rushing to solutions.

---

## 1. Create a Basic Object
**Task**: Create an object `person` with properties `name`, `age`, and `city`. Log each value.

---

## 2. Update and Add Properties
**Task**: Update `person`'s `city` to a new value. Add a new property `email`.

---

## 3. Access Properties Dynamically
**Task**: Write a function that accepts a key and returns the value from the `person` object.

---

## 4. Add Methods
**Task**: Add a method `greet` to `person` that logs a greeting using the `name`.

---

## 5. Loop Over Properties
**Task**: Use a `for...in` loop to print all keys and values in the object.

---

## 6. Use Nested Objects
**Task**: Add an `address` property to `person` which contains `street`, `zipcode`, and `country`. Access and log `zipcode`.

---

## 7. Array of Objects
**Task**: Create an array `users` with 3 user objects (each with `id`, `name`, `isActive`). Filter only active users.

---

## 8. Destructuring
**Task**: Destructure the `name` and `city` from the `person` object into variables.

---

## 9. Object.keys, Object.values, Object.entries
**Task**: Use all 3 methods on `person` and log the results.

---

## 10. Object Comparison (Bonus)
**Task**: Write a function to check if two objects have the same properties and values.

---

Happy practicing! When you’re ready, ask for object-based mini-challenges or quizzes.
