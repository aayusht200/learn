1. What does the following line do?

const link = document.querySelector("a");

Selects the first occurrence of an (anchor) tag in the document and assigns it to the link variable.

2. What does link.textContent = "Mozilla Developer Network"; do?

This assigns the link to have text content of (Mozilla Developer Network).

3. What does the following code do?

link.href = "https://developer.mozilla.org";

assigns the href value to be ("https://developer.mozilla.org")

4. Create a new element and store it in a variable called sect.

const sect=document.createElement("section");

5. Create a new paragraph and store it in a variable called para.

const para = document.createElement("p");

6. Give the paragraph some text content.

para.textContent = "This is the text Content assigned to P Element";

7. Append the paragraph to the section.

sect.appendChild(para);

8. Append the section to the body.

const body = document.querySelector("body");
body.appendChild(sect);

9. Give the section a class of "special".

sect.classList.add("special");

10. Remove the paragraph from the section.

sect.removeChild(para);

11. Create a button using createElement.

const btn = document.createElement("button");

12. Give it some text and append it to the body.

btn.textContent = "Click Me"; body.appendChild(btn);

13. Add a click event listener to the button that displays an alert saying “Button clicked!”.

btn.addEventListener("click", () => { alert("Button Clicked!"); });

14. How would you change the background color of the body using JavaScript?

body.style.backgroundColor = "grey";

15. How can you add a CSS class to an existing element?

const heading = document.querySelectorAll("h3"); heading.forEach((head) => { head.style.color = "White"; });
