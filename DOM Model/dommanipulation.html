🧠 DOM Manipulation Practice Questions

📁 Create & Select Elements

  1. Select an element with the class .header and log it to the console.
    • const header = document.querySelector("h1");
    • console.log(header);
  2. Create a new <section> element and give it a class of "container".
    • const sect = document.createElement("section");
    • sect.classList.add("container");
  3. Add a heading (<h2>) inside your new section with the text "Welcome to My Site!".
    • const headerTwo = document.createElement("h2");
    • headerTwo.textContent = "Welcome to my site!"; sect.appendChild(headerTwo);
  4. Append the entire section to the <body> of the page.
    • const content = document.querySelector(".dom");
    • content.appendChild(sect);

🎨 Style with JavaScript

  1. Change the background color of the body to #f0f0f0 using JavaScript.
    • content.style.backgroundColor = "#f0f0f0";
  2. Add padding of 2rem to the section using .style.
    • sect.style.padding = "2rem";

🖱 Event Listeners

  1. Create a <button> with the text "Toggle Theme" and append it to the section.
    • const btn = document.createElement("button");
    • btn.textContent = "Toogle Theme";
    • sect.appendChild(btn);
  2. Write an event listener that toggles a class "dark-theme" on the <body> when the button is clicked.
    • btn.addEventListener("click", () => { content.classList.toggle("dark-theme"); });
  3. In your CSS, define .dark-theme to have a black background and white text.
    • .dark-theme { background-color: black; color: white; }

🧹 Clean & Replace

  1. Create a paragraph with the text "This content will be removed.", append it, and then remove it with JavaScript after 2 seconds.
    • const removedPara = document.createElement("p");
    • removedPara.textContent = "This content will be removed";
    • sect.appendChild(removedPara);
    • window.addEventListener("load", () => {
      setTimeout(() => {
      removedPara.classList.toggle("removed-para");
      }, 2000);
      });
  2. Replace the content of the heading inside your section with "You toggled the theme!" when the button is clicked.
    • btn.addEventListener("click", () => { content.classList.toggle("dark-theme"); headerTwo.textContent = "You toggled the theme!"; });
