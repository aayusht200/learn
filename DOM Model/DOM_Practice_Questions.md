
# 🧠 DOM Manipulation Practice Questions

## 📁 Create & Select Elements

1. Select an element with the class `.header` and log it to the console.
2. Create a new `<section>` element and give it a class of `"container"`.
3. Add a heading (`<h2>`) inside your new section with the text **"Welcome to My Site!"**.
4. Append the entire section to the `<body>` of the page.

## 🎨 Style with JavaScript

5. Change the background color of the `body` to `#f0f0f0` using JavaScript.
6. Add padding of `2rem` to the section using `.style`.

## 🖱 Event Listeners

7. Create a `<button>` with the text **"Toggle Theme"** and append it to the section.
8. Write an event listener that toggles a class `"dark-theme"` on the `<body>` when the button is clicked.
9. In your CSS, define `.dark-theme` to have a black background and white text.

## 🧹 Clean & Replace

10. Create a paragraph with the text **"This content will be removed."**, append it, and then remove it with JavaScript after 2 seconds.
11. Replace the content of the heading inside your section with `"You toggled the theme!"` when the button is clicked.
