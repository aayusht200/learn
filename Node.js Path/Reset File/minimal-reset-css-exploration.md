# 📝 Minimal Reset CSS — Exploration Exercises

Your task is to discover browser default styles and gradually build your own **minimal reset stylesheet**.  
Open a blank HTML file and follow each section.

---

## 1. Headings

- Add `<h1>`, `<h2>`, `<h3>` elements.  
- **Question:** Do they have margins applied by default?  
- **Task:** Write CSS to remove or adjust them.

---

## 2. Lists (ul, ol)

- Add an unordered list:  
  ```html
  <ul>
    <li>One</li>
    <li>Two</li>
  </ul>
  ```
- **Question:** Do you see padding/indentation on the left?  
- **Task:** Reset it so lists align flush with the container edge.

---

## 3. Paragraphs

- Add `<p>Some text</p>`.  
- **Question:** Do paragraphs have default top/bottom margins?  
- **Task:** Remove them and compare.

---

## 4. Body element

- Add a background color to `<body>`.  
- **Question:** Do you notice a white strip around the edges? Where is it coming from?  
- **Task:** Reset that.

---

## 5. Images

- Add an `<img>` with a small width (e.g., 200px).  
- **Question:** Does it sometimes create tiny gaps below it? Why?  
- **Task:** Fix it with a reset rule.

---

## 6. Box-sizing

- Add a `<div>` with padding and width set in CSS.  
- **Question:** Does the element end up bigger than you expected?  
- **Task:** Adjust the `box-sizing` so width behaves intuitively.

---

⚡ By the end, you’ll have discovered quirks on your own and assembled a **minimal reset stylesheet** tailored to your observations.
